实现总结：方向三（Graph-COL）+ 方向六（Policy-TTI）

  新增文件

  src/graph_col.py — Graph-COL 核心模块：
  - build_concept_groups() — 从 CUB attributes.txt 按 28 个语义前缀构建概念分组（如 has_wing_color、has_bill_shape 等）
  - ConceptGroupGNN — 组内注意力聚合模块：每个概念的预测 = 原始 logit + α·组内加权均值，使同组概念共享上下文                                                    
  - GraphCOLLoss — 三级组结构损失：                                                                         
    - 组级 COL：同类→组特征相似，异类→组特征正交                                                                                                                
    - 组间正交：不同语义组的激活模式应低相关                                                                                                                    
    - 组内一致性：同组概念对同类样本应高度相关                                                                                                                  
                                                                                                                                                                
  src/policy_tti.py — Policy-TTI 核心模块：                                                                                                                     
  - PolicyNetwork — 轻量 MLP（312→64→64→28），输入概念置信度，输出组选择概率                                                                                    
  - PolicyTTITrainer — REINFORCE 训练器，奖励 = 熵降低量，带折扣和基线方差削减                                                                                  
  - policy_intervention() — 推理时贪心选择干预组                                                                                                                
                                                                                                                                                                
  修改的文件                                                                                                                                                    
                                                                                                                                                                
  - template_model.py — 新增 ConceptGroupAggregator，Inception3 接受 graph_col/concept_groups/n_groups 参数，前向传播中融合组内上下文                           
  - models.py — ModelXtoCY 传递 graph_col 参数并构建概念分组                                                                                                    
  - train.py — train_X_to_Cy 传递 graph_col 参数到模型                                                                                                          
  - train_util.py — 训练循环中集成 Graph-COL 损失计算                                                                                                           
  - utils.py — 新增 6 个 CLI 参数：-graph_col, -graph_col_w, -policy_tti, -policy_lr, -policy_epochs, -policy_hidden_dim, -policy_max_steps                     
  - tti.py — 新增 policy 干预模式，自动训练/加载策略网络                                                                                                        
                                                                                                                                                                
  使用方式                                                                                                                                                      
                                                                                                                                                                
  训练（带 Graph-COL）：                                                                                                                                        
  python experiments.py CUB Coop --seed 42 -use_aux -use_attr -col -graph_col -graph_col_w 1.0 -connect_CY -b 64 -e 200 -lr 0.001 -pretrained                 
                                                                                                                                                                
  TTI 评估（带 Policy-TTI）：                                                                                                                                   
  python experiments.py CUB TTI --seed 42 -policy_tti -policy_epochs 50 -mode policy                                                                            
                                                                                                                                                                
  所有修改向后兼容——不带 -graph_col 和 -policy_tti 时行为与原代码完全一致。
