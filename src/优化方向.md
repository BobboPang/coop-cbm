  方向一：动态自适应的 COL 损失权重

  现有问题（src/col.py:6-23）

  当前 COL 对所有 312 个概念一视同仁，使用固定 gamma=0.5：
  loss = (1.0 - pos_pairs_mean) + self.gamma * neg_pairs_mean

  且在 train_util.py:96-97 中 COL 与属性损失权重也是硬编码常量：
  losses.append(args.col_w * loss_op)
  losses.append(0.001 * attr_op)  # 硬编码 0.001

  创新方案：概念重要性感知的自适应 COL

  - 为每个概念 $c_i$ 计算其对最终分类的贡献度（如梯度大小或互信息），据此动态调整该概念的正交化强度
  - 对分类高度相关的概念（如"有翅膀"）加强正交化，对弱相关概念放松约束
  - 理论依据：强迫所有概念等强度正交会损害弱语义概念的预测精度，产生不必要的性能代价

  # 改进思路：每个概念独立的 gamma
  concept_importances = compute_gradient_importance(model, loader)  # 新增
  loss = sum([
      (1.0 - pos_mean_i) + gamma_i * neg_mean_i
      for i, gamma_i in enumerate(concept_importances)
  ])

  方向二：概念不确定性量化与置信度感知的 TTI

  现有问题（src/eval/tti.py:61-75）

  TTI 的熵计算仅用于选择干预哪个概念，而模型本身输出的是点估计，无法区分"模型对该概念很有把握但预测错了"vs"模型本身对该概念不确定"：
  # tti.py:63: 只用 sigmoid 值做伪置信度
  attr_logit = attr_preds_sigmoid[attr_idx]

  创新方案：概率化概念瓶颈（Probabilistic CBM）

  - 将每个概念头改为输出分布参数 (μ, σ²)（高斯假设）或 Dropout 集成
  - 不确定性高的概念自动降低其在 C→Y 路径中的权重
  - TTI 时优先干预不确定性高且熵降低量大的概念，形成双维度优先级

  这直接提升了 TTI 曲线的斜率，即更少干预即可恢复更多精度，可解释性指标显著改善。

  方向三：概念结构依赖建模（Graph-COL）

  现有问题（template_model.py:179-181）

  每个概念使用独立的 FC 头预测，完全忽略概念间的语义关联：
  for i in range(self.n_attributes):
      self.all_fc.append(FC(2048, 1, expand_dim))  # 312 个独立头

  在 CUB 数据集中，概念具有明显的层次结构（如"翅膀颜色"、"翅膀形状"、"翅膀纹理"同属翅膀组，tti.py 的 attr_group_dict 已经对此有 28 组划分，但训练时完全没利用）。

  创新方案：层次感知的 Graph-COL

  - 构建概念关系图 $G$：组内概念边为正向（应协同激活）、组间概念边为负向（应正交）
  - 在 COL 中引入图结构约束，用 GNN 聚合组内概念后再计算正交损失
  - 组内概念在空间上应聚类，不同组在空间上应正交

  现有 COL：以类别标签 Y 区分正负对
  Graph-COL：以概念组 G 区分正负对，细粒度对齐语义结构

  方向四：信息泄漏的显式抑制

  现有问题（template_model.py:252-256）

  Coop-CBM 的 C→Y 路径和直接 X→Y 路径并行存在，模型可以绕过概念瓶颈：
  # 前向传播中概念预测和类别预测路径相互独立
  for fc in self.all_fc:
      out.append(fc(x))           # 概念预测：x → concept
  if self.cy_fc is not None:
      out[0] += self.cy_fc(...)   # 类别预测可接收概念作为补充

  即 outputs[0]（直接类别预测）使用的特征 x（2048维）与概念预测使用的是同一个 x，该 x 中包含远超概念所能描述的信息，造成信息泄漏。

  创新方案：互信息正则化的概念完备性约束

  - 添加损失项：最小化概念瓶颈表示 $\hat{C}$ 与残差信息 $x - \text{proj}(\hat{C})$ 之间的互信息
  - 即强迫所有对 Y 有用的信息必须通过概念瓶颈传递，而非直接从 x 泄漏
  - 具体实现可用 MINE 或 VIB（变分信息瓶颈）估计互信息

  方向五：概念空间的注意力定位

  现有问题

  模型对图像的处理是全局 average pooling 后直接预测概念（template_model.py:244），无法告诉用户"哪个图像区域触发了该概念"：
  x = F.adaptive_avg_pool2d(x, (1, 1))  # 空间信息完全丢失
  x = x.view(x.size(0), -1)             # N x 2048

  创新方案：空间感知的概念预测头（Spatial-CBM）

  - 保留空间特征图 (N, 2048, 8, 8) 不做全局池化
  - 为每个概念学习一个空间注意力权重，提取对应区域的特征用于预测
  - 输出：每个概念激活时对应的图像热力图（Concept Saliency Map）
  - 这使模型具备"哪个概念在图像哪个位置激活"的可视化能力，大幅提升用户信任

  可以在 TTI 评估中新增指标：干预某概念后，与该概念对应的注意力区域是否发生显著变化，作为空间可解释性的定量指标。

  ---
  方向六：可学习的测试时干预策略（Policy-TTI）

  现有问题（tti.py:388-411）

  当前 TTI 评估中，干预顺序由启发式熵方法决定，且所有样本使用相同的干预顺序：
  for n_replace in list(range(args.n_groups + 1)):
      acc = simulate_group_intervention(args.mode, ...)

  创新方案：基于强化学习的主动概念查询策略

  将 TTI 建模为一个主动学习问题：
  - 状态：当前已知概念的置信度向量
  - 动作：选择查询哪个下一个概念
  - 奖励：查询后分类熵的降低量
  - 训练一个轻量策略网络，在最少查询次数下最大化分类准确率

  与当前的贪心熵策略相比，可以在 TTI 曲线的前几步（1-5组干预时）获得更快的精度恢复速度，这是论文中最直观的可解释性改进指标。
